# VIRTURA Website

VIRTURA 对外业务官网。独立于 Collective 与 SpacePort。

## 入口关系

- `virtura.space`：业务官网与项目咨询
- `collective.virtura.space`：成员、艺术作品与公共项目档案
- `spaceport.virtura.space`：工具、研究、实验与长期档案

## 本地预览

直接打开 `index.html`，或在此目录启动任意静态文件服务器。

## 内容边界

案例只陈述 VIRTURA 实际承担的创意、媒体内容、互动、实时系统、空间采集、技术整合或现场执行职责；不将第三方 LED 硬件、搭建或完整展览策划归为团队独立交付。
